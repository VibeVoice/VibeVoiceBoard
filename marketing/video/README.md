# marketing/video

Screen recordings from the phone, unedited. 1080 x 2340, H.264, with the narration track intact.

| File | Length | What it shows |
|---|---|---|
| `background-dictation.mp4` | 25 s | Dictation started in Keep Notes, the app left, the floating mark on the home screen, the foreground-service notification reading *"VibeVoice is listening / Waiting for speech… / Stop"*, then back in the app with the transcript having continued the whole time |
| `gestures.mp4` | 19 s | The two ways to start a session: the mark in the toolbar, and holding the space bar |

## Why `background-dictation.mp4` is kept as it is

It is the evidence for Play's **foreground service** declaration, which claims that the service runs
only during a session and is visible while it does. A cut that tightened it would be a cut that
removed the notification or the moment of leaving the app -- which is the whole proof. The spoken
commentary is left in for the same reason: it narrates the claim the declaration makes.

Google wants a link rather than a file. Unlisted YouTube is what the reviewer can always open;
"private" is the one setting that fails, because then nobody but the account owner can see it.

## What still needs re-recording

Neither has **Show taps** enabled (Developer options), so a viewer cannot see where a finger lands.
That is tolerable for the declaration, where the notification carries the argument, and not tolerable
for a store video, where the point is that a person starts this with one gesture.
